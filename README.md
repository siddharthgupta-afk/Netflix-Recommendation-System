# Netflix Recommendation System 🎬

A Machine Learning based Netflix Recommendation System that recommends movies and TV shows based on genres, similarity scores, and user preferences.

---

## 📌 Project Overview

This project uses Machine Learning and recommendation techniques to suggest Netflix content similar to a selected movie or show.

The system analyzes Netflix titles and recommends relevant content using feature engineering and similarity-based approaches.

---

## 🚀 Features

- Netflix Movie & TV Show Recommendations
- Similarity-Based Recommendation Engine
- Data Cleaning & Preprocessing
- Feature Engineering
- Machine Learning Workflow
- Exploratory Data Analysis
